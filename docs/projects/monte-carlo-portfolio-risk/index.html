What Happens to Diversification in a Crisis?

How does a shift in correlations change the modeled losses of a hypothetical equity portfolio when sector volatilities and portfolio weights are held fixed?

First feature: Historical sector returns

The first step is to load daily returns for three US equity sectors, align the series by date, and plot their cumulative returns from a common starting value of 100.

Data source

The project will use historical sector returns from the Kenneth R. French Data Library. The portfolio weights and simulated scenarios will be hypothetical.

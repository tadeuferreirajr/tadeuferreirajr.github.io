How the model works

Data. We use the last available adjusted close in each completed calendar month. Each monthly return is the current month-end close divided by the previous month-end close, minus one. The sample uses only months with returns for all selected assets. Source: Yahoo Finance, adjusted closes in USD. Download monthly returns (CSV).

Example. The first shared observation is December 2004. For each fund, divide its December month-end close by its November month-end close and subtract one.

Annualization. We multiply the sample mean monthly return by 12 and the sample covariance matrix by 12. Portfolio volatility is the square root of the weighted annualized covariance. The return is an arithmetic estimate, distinct from a compounded annual return (CAGR).

Frontier. Weights add to 100% and are constrained to be nonnegative. The curve traces long-only portfolios from minimum variance to maximum sample mean return. For each point, the optimizer trades off sample variance against sample mean return. The assumed weights are constant each month. The model excludes trading costs and taxes. Results describe the selected historical sample and are provided for education.
